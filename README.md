# 社内ツール案内アプリ（第1版）

「やりたいこと」から社内の最適なツールを逆引きする案内アプリです。要件は [docs/requirements.md](docs/requirements.md) を参照してください。

> 第1版は画面の試作です。データはすべて架空で、`src/lib/mock-data.ts` に入っています。
> 画面での操作（届出・公開など）はメモリ上だけで行われ、再読み込みすると元に戻ります。
> データベースへの接続と社内アカウントでのログインは、今後の手順で対応します。

## 使い方

```powershell
npm install
npm run dev
```

Edge で http://localhost:3000 を開きます。画面右上の「表示の立場（試作用）」で、一般社員と情報システム部門の見え方を切り替えられます。

## 画面と機能（要件定義書 3章との対応）

| 画面 | パス | 機能 |
|---|---|---|
| 探す | `/` | F1 やりたいことから探す、F2 カテゴリから探す |
| ツール詳細 | `/tools/[id]` | F3 ツール詳細を見る |
| 比較 | `/compare` | F4 候補を比較する（2〜3個） |
| 届け出る | `/submit` | F5 新規ツールを届け出る、F8 差し戻された届出を修正する |
| 届出の確認（情シスのみ） | `/admin/review` | F6 確認・公開、F7 差し戻し、F9 削除 |
| ツール情報の更新（情シスのみ） | `/tools/[id]/edit` | F10 ツール情報を更新する |
| 変更履歴（情シスのみ） | `/admin/history` | F11 変更履歴を見る |

## 構成

- Next.js（App Router）＋ shadcn/ui ＋ Tailwind CSS
- `src/lib/` … 型・架空データ・検索の仕組み
- `src/components/` … 画面の状態管理・共通部品（`ui/` は shadcn/ui の部品）
- `src/app/` … 各画面

## 補足

- 社外への送信や外部サービスへの保存は行いません。フォントも Windows 標準の日本語フォントを使い、外部から読み込みません。
- 鍵・パスワードはコードに書きません。
- 運用部門（情報システム部門）で維持・保守する前提です。
